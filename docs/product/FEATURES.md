# Product feature map

## MVP (public beta)
- Telegram onboarding
- wallet balance and transaction history
- manual/admin wallet credit (before payment gateway launch)
- live Hetzner catalog sync
- country/location -> plan -> OS selection
- transparent hourly sell price
- create server
- server list/details
- power on/off/reboot
- delete with explicit confirmation
- automatic hourly billing/finalization
- low-balance warnings and safe auto-delete policy
- user notifications for provisioning/deletion/errors
- admin user/server/provider-account search
- audit log

## V1
- Iranian payment gateway
- coupons/referrals
- SSH public key management
- rebuild/rescue
- snapshots/backups
- firewalls
- rDNS
- Primary/Floating IP controls where supported
- volumes/private networks
- invoice/usage statement
- maintenance mode per provider/location/plan
- abuse-case workflow

## V2
- web customer panel
- multiple Hetzner provider accounts/projects
- provider account allocator based on quota/health/rate limits
- second cloud provider
- first Iranian provider adapter
- API tokens for customers
- team/organization accounts
- scheduled auto-delete / TTL servers
- templates/cloud-init presets

## Later
- Kubernetes/app templates
- managed services marketplace
- dedicated server integration
- dynamic FX and multi-currency wallets
- reseller/white-label accounts
- usage analytics and forecasting
